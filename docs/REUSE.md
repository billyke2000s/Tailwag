## Capability decisions

Reuse native ASM contacts, scheduling/diary, task/rota/training, stock, forms/manual approvals, documents/signatures, staff/TOTP/permissions/audit, search/reporting and imports/exports. Reuse native notification/cron foundations but gate real delivery until configured and tested. Use a hosted donation provider only where actually needed; no card storage or duplicate payments ledger. Public UI is coherent server-rendered HTML with responsive CSS, requiring no extra client component framework. Native UI receives scoped styling without replacing working action handlers.

No disconnected code fragments or overlapping CRM systems are combined. Complete inherited capability groups and their retained/adapted/gated disposition are listed in FEATURE-INVENTORY.md. Native internal imports are explicitly coupled to the pin; upgrading requires tests, reviewed patches and restore validation.
