# Original prototype

The React/Vite application at the repository root remains a dog/cat matching demonstration with intentional sample content and offline generators. The Android/PWA v1.2.1 release is independent of the new operational platform.

- [Prototype release](https://github.com/billyke2000s/Tailwag/releases/tag/v1.2.1)
- [Original creator](https://github.com/fpr8653-afk/tailwag)

Use `npm ci`, `npm run dev`, `npm run lint`, `npm test` and `npm run build`. Android source is in android/. The APK is a debug-signed evaluation build, not a production distribution or a client for live shelter records. See the versioned release documentation for its exact verification and limitations.
