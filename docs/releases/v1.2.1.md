## Community repair preview

This release is repair work for a mate's original prototype. **The idea and original files belong to [fpr8653-afk/tailwag](https://github.com/fpr8653-afk/tailwag); billyke2000s does not claim original authorship.** Original notices and credits are preserved.

### Included

- Upstream dog/cat functionality through commit f993919, including cat profiles, catios and feline sounds.
- Correctly bundled local photos and offline fallbacks.
- Local profile, chat, check-in, discovery and preference persistence.
- Repaired filtering, rapid swipe handling, rewind and meetup shortcuts.
- Data-driven health labels, unread state and Android Back/modal handling.
- Complete Gradle wrapper/resources, bundled Android app and canonical project ZIP.
- Documentation, contribution templates, regression checks and automated preview packaging.

### Downloads

- **TailWag-1.2.1-debug.apk** — Android 7.0+ test install.
- **TailWag-Android-Project.zip** — Android source with frontend assets bundled.
- **SHA256SUMS.txt** — SHA-256 checksums for the two build assets.

The release workflow publishes only after web/type/regression checks, Android compilation and APK signature verification succeed. See the linked Actions run for this release's actual results. The earlier repair baseline also passed six Node tests, eight browser checks and an independent exported-project build locally.

### Known limitations

This remains a prototype: profiles, activity, ratings, matches, owner replies and playdates are simulated. Data is device-local. External avatars/fonts use local/system fallbacks offline. Wingman generates local template text without a cloud provider key. No physical-device or emulator verification is claimed for this preview. Development signing keys can differ between builds, so Android may require uninstalling an older test APK; save needed test data first.
