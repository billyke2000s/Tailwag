# Contributing

Read AGENTS.md and DEVELOPMENT.md. Open a focused issue or PR describing the operational problem, changed behaviour and evidence. Use synthetic examples. Include tests for meaningful workflow/security changes and documentation for changed setup or operations. Report blocked checks honestly.

Preserve attribution and licence notices. Public source is not automatically reusable: check the licence before copying. Do not silently relicense inherited TailWag files. New operational code under platform/ is GPL-3.0; see THIRD-PARTY.md.

Never attach live exports, care instructions, foster addresses, credentials or private screenshots. Security issues follow SECURITY.md. Avoid unrelated redesigns and duplicate systems of record. Every public control must lead to an implemented workflow or a clear unavailable state.
